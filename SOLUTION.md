## Решения

Матчи со статусом scheduled отображаются в фильтре «Предстоящие», а со статусом finished — в фильтре «Завершённые». Матчи со статусами live и postponed доступны в разделе «Все», поскольку для них нет отдельных фильтров.

Дату матча форматирую с помощью Intl.DateTimeFormat для русского языка. Если дата отсутствует, показывается сообщение «Дата не назначена». Если счёт отсутствует, вместо него отображается прочерк. Для матчей в прямом эфире показывается минута матча, если она есть в данных.

## Дополнительная функция

Выбрала поиск по названию клуба. Он помогает быстрее находить нужные матчи, особенно когда список большой. Реализовала поиск по названиям домашней и гостевой команд. Поиск работает без учёта регистра и совместно с фильтрами по статусу матча.
